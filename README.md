# Инструмент визуализации графа зависимостей (Этап 1)

## 1. Общее описание
CLI-приложение для визуализации графа зависимостей менеджера пакетов. 
Данный этап представляет собой минимальный прототип с конфигурацией через аргументы командной строки.

## 2. Описание всех функций и настроек
Приложение поддерживает следующие параметры командной строки:
- `-p`, `--package` (обязательный): Имя анализируемого пакета.
- `-r`, `--repo` (обязательный): URL-адрес репозитория или путь к файлу тестового репозитория.
- `-t`, `--test-mode`: Флаг режима работы с тестовым репозиторием.
- `-v`, `--version` (обязательный): Версия пакета в формате X.Y.Z.
- `-o`, `--output`: Имя сгенерированного файла с изображением графа (по умолчанию `graph.png`).
- `-d`, `--max-depth`: Максимальная глубина анализа зависимостей (по умолчанию 3, допустимо от 1 до 10).
