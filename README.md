# depviz (Вариант 15)

## Этап 2. Сбор данных

### Общее описание
CLI-приложение для визуализации графа зависимостей npm-пакетов. На данном этапе
реализовано получение информации о **прямых зависимостях** заданного пакета
заданной версии. Менеджеры пакетов и сторонние библиотеки для получения
зависимостей **не используются** — `package.json` загружается и разбирается
самостоятельно.

### Описание функций и настроек
Настройки задаются опциями командной строки (те же, что на этапе 1):

- `--package` — имя анализируемого пакета (обязательно).
- `--source` — URL репозитория или путь к файлу тестового репозитория (обязательно).
- `--test-mode` — режим работы с тестовым репозиторием.
- `--pkg-version` — версия пакета (по умолчанию `latest`).
- `--output` — имя файла с изображением графа (по умолчанию `graph.png`).
- `--max-depth` — максимальная глубина анализа (целое число от 0 до 100, по умолчанию 3).

Функции модулей:
- `src/cli.js` — разбор и валидация аргументов командной строки.
- `src/fetcher.js` — загрузка `package.json` по URL или из локального файла.
- `src/parser.js` — разбор `package.json` и извлечение блока `dependencies`.
- `src/main.js` — точка входа: получение и вывод прямых зависимостей.

### Команды для сборки проекта и запуска тестов
Установка зависимостей (только для тестов, не для работы с пакетами):
```bash
npm install

Запустить напрямую:
python src/main.py --package express --source https://raw.githubusercontent.com/expressjs/express/master/package.json
Запуск тестов:
python -m pytest tests/ -v
