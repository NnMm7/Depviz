# depviz (Вариант 15)

## Этап 1. Минимальный прототип с конфигурацией

### Общее описание
CLI-приложение для визуализации графа зависимостей npm-пакетов. На данном этапе реализован разбор параметров командной строки, их валидация и вывод в формате «ключ-значение».

### Описание функций и настроек
- `--package` — имя анализируемого пакета (обязательно).
- `--source` — URL репозитория или путь к файлу тестового репозитория (обязательно).
- `--test-mode` — режим работы с тестовым репозиторием.
- `--pkg-version` — версия пакета (по умолчанию `latest`).
- `--output` — имя файла с изображением графа (по умолчанию `graph.png`, допускаются `.png`, `.svg`, `.pdf`).
- `--max-depth` — максимальная глубина анализа (целое число от 0 до 100, по умолчанию 3).
