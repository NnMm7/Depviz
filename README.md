# Depviz — визуализация графа зависимостей (Вариант №15)

Учебный проект по дисциплине «Конфигурационное управление».
Утилита командной строки для анализа прямых и транзитивных зависимостей npm-пакетов.

## Общее описание

На данном этапе (Этап 3) реализован инструмент, который:
1. Загружает файл `package.json` по указанному URL (без использования менеджеров пакетов, только стандартная библиотека `urllib`).
2. Извлекает прямые зависимости (из секций `dependencies`, `devDependencies` и др.).
3. Строит граф зависимостей (с учетом транзитивности) и выполняет обход алгоритмом **DFS с рекурсией**.
4. Обрабатывает циклические зависимости и ограничивает глубину анализа.
5. Поддерживает тестовый режим, позволяющий считывать граф из текстового файла.

## Описание функций и настроек

Все параметры задаются через опции командной строки:

* `--package` **(обязательно)** — имя анализируемого пакета (корневой узел графа).
* `--source` **(обязательно)** — URL репозитория (ссылка на `package.json`) или путь к файлу тестового репозитория (при использовании `--test-mode`).
* `--test-mode` — режим работы с тестовым репозиторием. Ожидает текстовый файл, где пакеты названы большими латинскими буквами (формат строк: `A B C` означает, что `A` зависит от `B` и `C`).
* `--pkg-version` — версия пакета (по умолчанию `latest`).
* `--output` — имя файла с изображением графа (по умолчанию `graph.png`, допускаются расширения `.png`, `.svg`, `.pdf`).
* `--max-depth` — максимальная глубина анализа зависимостей (целое число от 0 до 100, по умолчанию 3).
